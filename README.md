# 🏎️ Pixel Car Turbo

Mi primer videojuego arcade de autos creado desde cero en **C++** con la librería **raylib**.

## 🎮 Cómo jugar (Windows)
1. Haz clic en el archivo **`mi_auto.zip`** de la lista de arriba y presiona **Download** (o *View raw*).
2. Descomprime el archivo y haz doble clic en **`mi_auto.exe`**.

## 🕹️ Controles
* **Flechas del teclado (`↑` `↓` `←` `→`):** Mover el auto por la pista.
* **Barra espaciadora (`ESPACIO`):** Activar el **Nitro** (aumenta la velocidad y duplica los puntos).
* **`ENTER`:** Iniciar partida / Reiniciar en Game Over.

## ✨ Características
* Sistema de 3 vidas y récord máximo (`HIGH SCORE`).
* Tráfico enemigo con dificultad progresiva.
* Monedas doradas para recoger puntos extra y recargar nitro.
